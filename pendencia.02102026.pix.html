Etapa Administrativa • Negócio, Carências & Ganhos do Gestor VISÃO DE PRODUTO

Diagnóstico operacional das necessidades do usuário final do sistema.

O Que Vem Acontecendo Hoje? (Carências do Sistema Atual)

1. Falta de Autonomia nas Regras

O sistema aplica comportamentos fixos. O gestor precisa decidir se quer ligar/desligar: atalhos de cobrança no Zap, aviso de repasse ao dono e alerta de reajuste de 12 meses.

2. O Vácuo Jurídico do Fiador

A fiança é a garantia mais usada no Brasil. Hoje, locações registram só o inquilino. Em caso de cobrança, a imobiliária fica descoberta sem os dados do fiador (nome, CPF, Zap, endereço).

3. Vitrine Pública em Formato de Lista

A vitrine exibe imóveis em cartões horizontais compridos, cabendo apenas 1 ou 2 por tela. Os grandes portais usam Grade de Cards Verticais (lado a lado), com fotos em destaque e maior densidade visual.

O Que o Gestor Precisa
  • Central de Regras: Ligar/desligar alertas de cobrança, repasse ao dono e reajuste anual com 1 clique em Configurações.
  • Fiador em Todas as Telas: Ter o campo de Fiador disponível tanto ao cadastrar o imóvel, quanto ao alugar pelo catálogo ou fechar pelo CRM.
  • Vitrine Comercial Atraente: Site moderno em grade de 2 colunas com fotos grandes, carrossel de setas e clique na imagem que abre o formulário de proposta direto.
Seus Ganhos como Administrador (Dono do SaaS)
  • Conversão de Vendas do SaaS: Quando uma imobiliária testar os 30 dias grátis e ver a vitrine moderna em grade, o impacto visual fechará a assinatura.
  • Padrão ERP de Mercado: O SGI se consolida como uma ferramenta completa de retaguarda jurídica, financeira e de catálogo.
  • Zero Atrito no Suporte: Cada imobiliária configura o próprio fluxo, eliminando pedidos individuais de customização.

Supabase SQL Migration

Preparação das Tabelas `imobiliarias` e `contratos_locacao`

Utilizaremos a coluna preferencias jsonb na tabela imobiliarias. Isso permite salvar qualquer dicionário de configurações sem precisar alterar a estrutura da tabela novamente no futuro. Em contratos_locacao, adicionamos os atributos jurídicos do fiador: 

-- 1. Coluna expansível de preferências da imobiliária (Padrão JSONB escalável)
ALTER TABLE imobiliarias 
ADD COLUMN IF NOT EXISTS preferencias jsonb DEFAULT '{
  "notificar_zap_repasse": false,
  "lembrete_cobranca_zap": true,
  "alerta_reajuste_anual": true,
  "permitir_fiador": true
}'::jsonb;

-- 2. Atributos da Fiança Locatícia nos Contratos de Locação
ALTER TABLE contratos_locacao 
ADD COLUMN IF NOT EXISTS tem_fiador boolean DEFAULT false,
ADD COLUMN IF NOT EXISTS fiador_nome text,
ADD COLUMN IF NOT EXISTS fiador_cpf_cnpj text,
ADD COLUMN IF NOT EXISTS fiador_rg text,
ADD COLUMN IF NOT EXISTS fiador_whatsapp text,
ADD COLUMN IF NOT EXISTS fiador_email text,
ADD COLUMN IF NOT EXISTS fiador_endereco text;
