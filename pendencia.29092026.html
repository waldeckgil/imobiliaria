1. Regra de Negócio & Estratégia: O "Lead Paywall" (FOMO)

Quando uma imobiliária assinante entra em Modo Somente Leitura (inadimplente após o término da carência):

1. Vitrine Pública Online:

O site (index.html) NÃO pode sumir da internet. Ele deve continuar recebendo visitantes e formulários normalmente.

2. Leads Chegam no CRM:

O contato enviado pelo cliente externo cai normalmente na Central de Atendimentos (leads.html). O gestor vê o interesse registrado.

3. Telefone Ofuscado & Trava Zap:

O WhatsApp do interessado é mascarado com 🔒 (XX) 9****-**** e o botão "Chamar" é bloqueado exigindo a renovação da assinatura.

ETAPA 1: Banco de Dados (Supabase SQL Editor)

Abra o SQL Editor do painel Supabase do projeto e execute este script completo para atualizar as políticas RLS: 

-- 1. Permite que o público visualize vitrines ativas OU em modo leitura (read_only)
DROP POLICY IF EXISTS "Publico le dados vitrine imobiliaria" ON imobiliarias;
CREATE POLICY "Publico le dados vitrine imobiliaria" 
ON imobiliarias FOR SELECT TO public 
USING (status IN ('active', 'read_only'));

-- 2. Permite que o público consulte imóveis ativos de imobiliárias em read_only
DROP POLICY IF EXISTS "Publico le imoveis ativos na vitrine" ON imoveis;
CREATE POLICY "Publico le imoveis ativos na vitrine" 
ON imoveis FOR SELECT TO public 
USING (ativa = true AND status = 'Disponível');

-- 3. Força a recarga do cache de schemas do Supabase PostgREST
NOTIFY pgrst, 'reload schema';
