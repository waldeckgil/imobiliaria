2. Arquitetura de Execução Serverless (Vercel + Supabase)

Como você utiliza Vercel e Supabase no plano gratuito, não precisamos contratar VPS, DigitalOcean ou servidores pagos. Usaremos as Vercel Serverless Functions (pasta /api):

1. /api/pix-gerar.js

Função servidora que recebe o imobiliaria_id, consulta a API do Mercado Pago e devolve a string e imagem do QR Code PIX em 300ms.

2. /api/pix-webhook.js

O robô ouvinte. Quando o cliente paga no banco dele, o Mercado Pago avisa esta rota com o evento payment.updated.

3. Supabase RPC / SQL

O webhook conecta no Supabase com chave administrativa, muda o status para 'active', estende a data e emite o recibo.

3. Checklist Prático de Implantação (Roteiro de 5 Etapas)

Siga este roteiro na ordem cronológica exata amanhã.

1

Conta Mercado Pago & Credenciais de Produção

1. Acesse o portal oficial de desenvolvedores: mercadopago.com.br/developers.

2. Crie uma aplicação chamada "SGI SaaS Mensalidades".

3. Copie o seu Access Token de Produção (começa com APP_USR-...). É essa chave que autorizará a emissão de PIX dinâmico.

Nota: Você não paga nada para criar a conta ou pegar o token.

2

Banco de Dados Supabase (Tabela de Configuração e Histórico)

Adicionaremos campos na tabela config_sistema para guardar seu token com segurança e em imobiliarias_mensalidades para registrar o ID da transação do Mercado Pago:

-- 1. Armazena o Access Token e Webhook Secret no console Master
ALTER TABLE config_sistema ADD COLUMN IF NOT EXISTS mp_access_token text;
ALTER TABLE config_sistema ADD COLUMN IF NOT EXISTS mp_webhook_secret text;

-- 2. Registra o ID da transação Mercado Pago no histórico de mensalidades
ALTER TABLE imobiliarias_mensalidades ADD COLUMN IF NOT EXISTS mp_payment_id text;

-- 3. Recarrega o cache do PostgREST
NOTIFY pgrst, 'reload schema';
3

Console Master (admin-master.html)

• Adicionar um campo na barra superior do console Master para você salvar o seu Access Token do Mercado Pago com 1 clique.

• Quando você salvar o token no Master, o sistema passa a emitir PIX do Mercado Pago imediatamente.

4

Backend Serverless no Vercel (Pastas /api)

Criaremos 2 pequenos arquivos JavaScript dentro da pasta /api do seu projeto no VS Code:

  • api/pix-gerar.js: Conecta com o Mercado Pago e retorna o QR Code dinâmico com o valor da imobiliária.
  • api/pix-webhook.js: Recebe a notificação do Mercado Pago, confere se o pagamento é real, estende +30 dias no Supabase e ativa a imobiliária.
5

Modal de Bloqueio no Dashboard (dashboard.html)

• Modificar o modal para exibir o seletor visual: [PIX Aprovado na Hora] vs [PIX Tradicional Manual].

• Na aba do Mercado Pago, exibir a imagem do QR Code + Botão "Copiar Código PIX" + um relógio de monitoramento que atualiza a tela do gestor assim que o webhook confirmar o pagamento.

4. Como Testaremos na Prática (Simulação Real de R$ 1,00)

1. No Master, ajustaremos temporariamente o plano da Imobiliária SGI para R$ 1,00.

2. No Master, marcaremos a imobiliária como "Bloqueada".

3. Entraremos no dashboard.html da imobiliária. O modal saltará com o QR Code de R$ 1,00.

4. Você abrirá o app do seu banco no celular e pagará o PIX de R$ 1,00.

5. O Teste de Fogo: Em menos de 5 segundos, sem tocar no teclado, o Dashboard fechará o modal sozinho, sumirá com a faixa de bloqueio e reativará a conta com vencimento para +30 dias!
